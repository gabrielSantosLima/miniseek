# miniseek — From Scratch to an LLM

Una guía de estudio interactiva, del cálculo a una LLM mínima basada en Transformer.

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://gabrielsantoslima.github.io/miniseek/)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[English](README.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es.md)

</div>

Un currículo capítulo a capítulo que cubre las matemáticas, los fundamentos de redes neuronales, los modelos de secuencia y los Transformers necesarios para entender e implementar una LLM mínima. La guía incluye ejemplos resueltos, laboratorios interactivos, quizzes y listas de dominio.

## Documentación

La guía de estudio está publicada en <https://gabrielsantoslima.github.io/miniseek/>.
