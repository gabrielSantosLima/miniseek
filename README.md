# miniseek — From Scratch to an LLM

An interactive study guide from calculus to a minimal Transformer-based language model.

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://gabrielsantoslima.github.io/miniseek/)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[English](README.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es.md)

</div>

A chapter-by-chapter curriculum covering the mathematics, neural-network foundations, sequence models, and Transformers needed to understand and implement a minimal LLM. The guide includes worked examples, interactive labs, quizzes, and mastery checklists.

## Documentation

The study guide is published at <https://gabrielsantoslima.github.io/miniseek/>.
