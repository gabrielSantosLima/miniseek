# miniseek — From Scratch to an LLM

Um guia de estudo interativo, do cálculo a uma LLM mínima baseada em Transformer.

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://gabrielsantoslima.github.io/miniseek/)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

[English](README.md) | [Português (Brasil)](README.pt-BR.md) | [Español](README.es.md)

</div>

Um currículo capítulo a capítulo que cobre a matemática, os fundamentos de redes neurais, os modelos de sequência e os Transformers necessários para entender e implementar uma LLM mínima. O guia inclui exemplos resolvidos, laboratórios interativos, quizzes e checklists de domínio.

## Documentação

O guia de estudo está publicado em <https://gabrielsantoslima.github.io/miniseek/>.
